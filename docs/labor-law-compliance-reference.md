## 各条文の詳細

---

### 第15条（労働条件の明示）

**要旨**  
使用者は、労働契約の締結に際し、労働者に対して**賃金・労働時間その他の労働条件を明示しなければならない**。

**必須明示事項（書面または電磁的方法）**

| 区分 | 明示事項 |
|---|---|
| 絶対的明示事項（必ず書面で） | 労働契約の期間、就業場所・従事すべき業務、始業・終業の時刻・休憩・休日・時間外労働の有無・交替制、賃金の決定/計算/支払い方法・締日/支払日、退職に関する事項（解雇含む） |
| 相対的明示事項（定めがあれば書面で） | 退職手当、臨時の賃金・最低保障額、食費・作業用品の負担、安全・衛生、職業訓練、災害補償、表彰・制裁、休職 |

**2024年4月改正（令和6年4月）追加事項**
- 就業場所・業務内容の「変更の範囲」の明示が義務化
- 有期契約では「更新上限の有無と内容」「無期転換申込権の発生」の明示が追加

**実装への反映**
- キーワード: `賃金`, `給与`, `月給`, `日給`, `時給`, `基本給`, `報酬`
- 未記載 → ❌（必須明示事項のため法定違反）

### 第20条（解雇の予告）

**要旨**  
使用者は、労働者を解雇しようとする場合においては、**少なくとも30日前にその予告をしなければならない**。30日前に予告をしない使用者は、**30日分以上の平均賃金（解雇予告手当）を支払わなければならない**。

**ポイント**
- 予告日数は平均賃金を支払った日数分だけ短縮可能
- 例: 解雇予告手当15日分を支払った場合 → 15日前予告で足りる

**実装への反映**
- キーワード（OK）: `解雇予告`, `30日前`, `三十日前`
- キーワード（⚠️）: `解雇`, `退職`（予告の詳細なし）
- 何もなし → ⚠️（記載義務はないが、重要な権利情報）

---

### 第21条（予告の適用除外）

**要旨**  
以下に該当する労働者には第20条の解雇予告は適用されない。ただし、一定期間継続使用された場合は適用される。

| 区分 | 予告不要の期間 |
|---|---|
| 日々雇用者 | 1か月を超えて引き続き使用されるまで |
| 2か月以内の期間を定めた契約 | 契約期間を超えるまで |
| 季節的業務（4か月以内） | 契約期間を超えるまで |
| 試の使用期間中 | 14日を超えるまで |

**試用期間との関係**
- 試用期間中（14日以内）は解雇予告なしで即時解雇が可能
- 14日を超えた場合は通常の第20条が適用される

**実装への反映**
- キーワード: `試用`, `試用期間`
- 試用期間は任意だが、定める場合は明示が望ましい → ⚠️（未記載）

### 第32条（労働時間）

**要旨**

```
第1項: 使用者は、労働者に、休憩時間を除き１週間について
       40時間を超えて、労働させてはならない。

第2項: 使用者は、1週間の各日については、労働者に、休憩時間を除き
       1日について8時間を超えて、労働させてはならない。
```

**法定労働時間の上限**

| 区分 | 上限 |
|---|---|
| 週 | 40時間（特例措置対象事業場は44時間） |
| 日 | 8時間 |

**特例措置対象事業場**（常時10人未満）: 商業、映画・演劇業（映画製作を除く）、保健衛生業、接客娯楽業 → 週44時間

**実装への反映**
- キーワード: `労働時間`, `所定労働時間`, `勤務時間`, `就業時間`
- 未記載 → ❌（法定必須明示事項）

---

### 第34条（休憩）

**要旨**

```
労働時間が6時間を超える場合: 少なくとも45分の休憩
労働時間が8時間を超える場合: 少なくとも1時間の休憩
```

**原則**
- 休憩は労働時間の途中に与えなければならない
- 休憩時間は一斉付与が原則（労使協定で変更可）
- 休憩中は自由に利用させなければならない

**実装への反映**
- キーワード: `休憩`, `休憩時間`
- 未記載 → ⚠️（確認要、ただし就業規則に委ねる場合もある）

---

### 第35条（休日）

**要旨**

```
第1項: 使用者は、労働者に対して、毎週少なくとも1回の休日を与えなければならない。
第2項: 前項の規定は、4週間を通じ4日以上の休日を与える使用者については適用しない。
```

**法定休日のルール**
- 原則: 週1日以上（曜日指定なし）
- 変形: 4週間に4日以上でも可（変形休日制、就業規則で起算日を定める必要あり）

**週休2日制について**
- 法律が求めるのは「週1日」のみ
- 「週休2日」は法定を上回る制度であり、記載があれば積極的にチェック

**実装への反映**
- キーワード（✅）: `週休2日`, `週に2日`, `週2日`
- キーワード（⚠️）: `休日`, `法定休日`, `週休`, `公休`（週何日か不明）
- 未記載 → ❌（必須明示事項）

---

### 第37条（割増賃金）

**要旨**

```
使用者が、時間外・休日・深夜に労働させた場合、通常の賃金に
割増賃金を加算して支払わなければならない。
```

**割増率の一覧**

| 種別 | 割増率 | 備考 |
|---|---|---|
| 時間外（法定外残業） | **25%以上** | 月60時間以内 |
| 時間外（月60時間超） | **50%以上** | 中小企業も2023年4月より適用 |
| 休日（法定休日）労働 | **35%以上** | |
| 深夜労働（22:00〜5:00） | **25%以上** | |
| 時間外＋深夜の重複 | **50%以上** | 25%+25% |
| 休日＋深夜の重複 | **60%以上** | 35%+25% |

**契約書でのチェックポイント**
- 割増率が数値（25%、1.25など）で明示されているか
- 「時間外手当を支払う」だけでは率が不明 → ⚠️

**実装への反映**
- キーワード（✅）: `割増賃金`, `割増率`, `25%`, `1.25`, `125%`, `時間外手当`, `残業代`
- キーワード（⚠️）: `時間外`, `残業`（割増率の記載なし）
- 未記載 → ⚠️（法定義務はあるが、契約書に必ずしも明示が必須ではない）

### 第39条（年次有給休暇）

**要旨**  
使用者は、その雇入れの日から起算して**6か月間継続勤務**し、**全労働日の8割以上出勤**した労働者に対して、継続し、または分割した有給休暇を与えなければならない。

**付与日数テーブル**

| 継続勤務期間 | 付与日数 |
|---|---|
| 6か月 | **10日** |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | **20日**（上限） |

**年5日の取得義務（2019年4月〜）**
- 10日以上の有給休暇が付与された労働者には、使用者が**年5日を指定して取得させる義務**がある（労基法39条7項）

**比例付与（短時間労働者）**
- 週所定労働日数が4日以下かつ週30時間未満の労働者には、所定労働日数に応じた比例付与

**実装への反映**
- キーワード: `有給`, `有給休暇`, `年次有給休暇`, `年休`
- 未記載 → ❌（付与は法定義務。契約書・就業規則への明示は労働者への説明義務の観点から重要）

---

### 第89条（就業規則の作成・届出）

**要旨**  
**常時10人以上**の労働者を使用する使用者は、就業規則を作成し、労働基準監督署に届け出なければならない。変更の場合も同様。

**就業規則の絶対的必要記載事項**

| 記載事項 | 内容 |
|---|---|
| 始業・終業時刻 | 休憩時間、休日、休暇（有給含む）、就業時転換 |
| 賃金 | 決定・計算・支払いの方法、締切・支払日、昇給 |
| 退職 | 解雇事由を含む |

**相対的必要記載事項**（定めがある場合のみ）: 退職手当、臨時賃金・最低賃金額、食費・作業用品の負担、安全衛生、職業訓練、災害補償、表彰・制裁、休職
