# 第三十九条（年次有給休暇）

使用者は、その雇入れの日から起算して六箇月間継続勤務し全労働日の八割以上出勤した労働者に対して、継続し、又は分割した十労働日の有給休暇を与えなければならない。
②　使用者は、一年六箇月以上継続勤務した労働者に対しては、雇入れの日から起算して六箇月を超えて継続勤務する日（以下「六箇月経過日」という。）から起算した継続勤務年数一年ごとに、前項の日数に、次の表の上欄に掲げる六箇月経過日から起算した継続勤務年数の区分に応じ同表の下欄に掲げる労働日を加算した有給休暇を与えなければならない。ただし、継続勤務した期間を六箇月経過日から一年ごとに区分した各期間（最後に一年未満の期間を生じたときは、当該期間）の初日の前日の属する期間における当該労働者の全労働日の八割未満しか出勤しなかつた場合においては、当該初日以後の一年間においては有給休暇を与えることを要しない。

| 六箇月経過日から起算した継続勤務年数 | 労働日 |
|---|---|
| 一年 | 一労働日 |
| 二年 | 二労働日 |
| 三年 | 四労働日 |
| 四年 | 六労働日 |
| 五年 | 八労働日 |
| 六年以上 | 十労働日 |

③　次に掲げる労働者（一週間の所定労働時間が厚生労働省令で定める時間以上の者を除く。）の有給休暇の日数については、前二項の規定にかかわらず、これらの規定による有給休暇の日数を基準とし、通常の労働者の一週間の所定労働日数として厚生労働省令で定める日数（以下この項において「通常の労働者の週所定労働日数」という。）と当該労働者の一週間の所定労働日数又は一週間以外の一定の期間における所定労働日数を厚生労働省令で定める方法により一週間の所定労働日数に換算した日数（以下この項において「当該労働者の週所定労働日数」という。）との比率を考慮して厚生労働省令で定める日数とする。
 - 一　一週間の所定労働日数が通常の労働者の週所定労働日数に比し相当程度少ないものとして厚生労働省令で定める日数以下の労働者
 - 二　週以外の一定の期間によつて所定労働日数が定められている労働者であつて前号の厚生労働省令で定める日数に相当するものとして厚生労働省令で定める日数以下の者
④　使用者は、当該事業場に、労働者の過半数で組織する労働組合がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては労働者の過半数を代表する者との書面による協定により、次に掲げる事項を定めた場合には、第一項から第三項までの規定による有給休暇を時間を単位として与えることができる。
 - 一　時間を単位として与えることができることとされる有給休暇の日数（五日以内に限る。）
 - 二　時間を単位として与えることができることとされる有給休暇一日の時間数（所定労働時間数（日ごとに所定労働時間数が異なる場合には、一年間における一日平均所定労働時間数。以下この号において同じ。）を下回らないものとする。）
 - 三　その他厚生労働省令で定める事項
⑤　使用者は、前各項の規定による有給休暇を労働者の請求する時季に与えなければならない。ただし、請求された時季に有給休暇を与えることが事業の正常な運営を妨げる場合においては、他の時季にこれを与えることができる。
⑥　使用者は、当該事業場に、労働者の過半数で組織する労働組合がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては労働者の過半数を代表する者との書面による協定により、第一項から第三項までの規定による有給休暇を与える時季に関する定めをしたときは、これらの規定による有給休暇の日数のうち五日を超える部分については、前項の規定にかかわらず、その定めにより有給休暇を与えることができる。
⑦　使用者は、第一項から第三項までの規定による有給休暇（これらの規定により使用者が与えなければならない有給休暇の日数が十労働日以上である労働者に係るものに限る。以下この項及び次項において同じ。）の日数のうち五日については、基準日（継続勤務した期間を六箇月経過日から一年ごとに区分した各期間（最後に一年未満の期間を生じたときは、当該期間）の初日をいう。以下この項において同じ。）から一年以内の期間に、労働者ごとにその時季を定めることにより与えなければならない。ただし、第五項又は第六項の規定による有給休暇を与えた場合においては、当該与えた有給休暇の日数（当該日数が五日を超える場合には、五日とする。）分については、この限りでない。
⑧　前項の規定にかかわらず、使用者が第一項から第三項までの規定による有給休暇を当該有給休暇に係る基準日より前の日から与え始める場合においては、厚生労働省令で定めるところにより、当該与え始める日（以下この条において「第一基準日」という。）から一年以内の期間（以下この条において「第一期間」という。）並びに当該第一基準日の翌日から一年を経過する日（以下この条において「第二基準日」という。）から次の第一基準日の前日（第二基準日から起算して一年以内の日に限る。）までの期間（以下この条において「第二期間」という。）に、それぞれ前項の日数の二分の一以上の日数を、労働者ごとにその時季を定めることにより与えなければならない。
⑨　使用者は、その雇入れの日から起算して六箇月以内の期間であつて厚生労働省令で定める期間（以下この項において「六箇月以内の期間」という。）に育児休業（育児休業、介護休業等育児又は家族介護を行う労働者の福祉に関する法律（平成三年法律第七十六号）第二条第一号に規定する育児休業をいう。以下この条において同じ。）を取得した労働者に対して、当該育児休業が終了した日（同法第九条の二第一項の規定により育児休業をした労働者にあつては、当該育児休業の終了後に出生時育児休業（同条第一項に規定する出生時育児休業をいう。以下この条において同じ。）の申出により出生時育児休業を取得した場合にあつては当該出生時育児休業が終了した日）の翌日（以下この項において「育児休業終了翌日」という。）から起算して六箇月を経過する日（以下この項において「六箇月経過日等」という。）が当該六箇月以内の期間の末日（以下この項において「期間末日」という。）後である場合においては、期間末日の翌日から六箇月経過日等（同法第九条の二第一項の規定による育児休業の申出があつた場合（以下この項において「出生時育児休業の申出があつた場合」という。）においては、厚生労働省令で定める日）までの間に、継続し、又は分割した十労働日（第一項の規定による有給休暇の日数が十労働日に満たない場合には当該日数）の有給休暇（以下この項において「育児休業後有給休暇」という。）を与えなければならない。ただし、出生時育児休業の申出があつた場合において、当該育児休業終了翌日から起算した期間が六箇月を経過していないときは、当該育児休業終了翌日から起算して六箇月を経過する日（以下この項において「六箇月経過日」という。）から次の第一基準日（育児休業後有給休暇に係る基準日以後にあるものに限る。）の前日までの間に、当該育児休業後有給休暇の日数（既に付与した育児休業後有給休暇の日数を除く。）を与えなければならない。
⑩　使用者は、第一項から第三項まで及び前三項の規定による有給休暇の期間又は第四項の規定による有給休暇に係る時間については、就業規則その他これに準ずるものにより、当該有給休暇の日の賃金として、平均賃金若しくは所定労働時間労働した場合に支払われる通常の賃金又はこれらの額を基準として厚生労働省令で定めるところにより算定した標準報酬日額に相当する額の賃金を支払わなければならない。ただし、当該事業場に、労働者の過半数で組織する労働組合がある場合においてはその労働組合、労働者の過半数で組織する労働組合がない場合においては労働者の過半数を代表する者との書面による協定により、その期間について健康保険法（大正十一年法律第七十号）第九十九条第一項に定める標準報酬日額に相当する額の賃金を支払う旨を定めたときは、これによらなければならない。
